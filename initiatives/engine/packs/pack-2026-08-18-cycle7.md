### `#tripwire-dead-on-arrival`

A test in the suite passed for four days while measuring nothing. Its probe asked a mounted volume
for a config file that was never put there, so the probe **skipped on every machine** — and the
assertion accepted the skip as a pass. It was green the whole time. The rule that came out of it:
assert a probe **ran** before asserting what it printed.

### `#the-two-attackers-agree`

Adversarial review here runs as two fresh agents on different surfaces — one on decision logic, one
on the shell/OS boundary. Across four such passes this cycle they returned 94 findings. Historically
their overlap has been near zero, which is the point: a single reviewer's blind spot is structural
rather than a matter of effort. On one pass they independently found and proved the *same five*
critical defects, and that agreement was itself the signal.

### `#the-fix-four-hours-old`

The worst defect one pass found was in code written four hours earlier — by the previous pass's own
fix round. Written down as a standing rule: *fixes produced by an adversarial pass are themselves
unattacked code.* It has now been recorded four times and been true each time.

### `#a-guard-that-blocks-the-normal-case`

A new isolation guard refused any symbolic link inside the runtime's home directory. Against test
fixtures that is fine. Against a **real** runtime home it refuses every dispatch after the first,
because the Python installer builds its package cache out of symlinks. A gate that blocks the normal
case gets switched off — for a good reason — taking the real protection with it. The property was
never "no links", it was "no link that escapes".

### `#the-copy-that-killed-the-process`

Copying that same runtime home did not throw an error. It took the whole Node process down with a
stack-buffer-overrun and no error text at all: no exception, no receipt, no diagnosis, the run simply
vanished. Three different copy modes, all identical. Bisected to package-cache symlinks whose targets
are absolute paths that only exist inside the container. Every fixture stayed green throughout,
because fixtures plant regular files.

### `#a-test-grepping-a-hash`

A check asserting "no ceiling value appears anywhere in this receipt" searched the whole record as
text — including a 64-character hexadecimal digest. The ceiling's four digits land inside such a
digest roughly 0.19% of the time. It finally rolled one, and the failure read exactly like a real
leak, because the assertion printed the record with the digits in it.

### `#the-field-that-was-true-when-written`

A routing row declared `hosted: local`. True the day it was written, and falsified the moment the
work moved to a hosted model — with nothing that reads the field noticing. It is the field a data
boundary consults to explain *where a document was about to go*, so a stale value made the boundary's
own explanation wrong on the one path whose entire job is to say that.

### `#the-model-was-the-confound`

A local 8-billion-parameter model failed to honour a one-shot output contract on five consecutive
real attempts, at four to six minutes each. The write-up at the time said "the runtime does not
reliably honour a one-shot contract". That framing was wrong. Given a properly-sized hosted model,
the same runtime, same container image, returned the contracted output on the **first** attempt, in
43 seconds. The measurement to keep: distinguish the tool from the thing you plugged into it.

### `#the-clock-nobody-set`

An appetite clock read 0.0 days for four days while work was happening. The phase close recorded
that "the phase itself was not the overrun; the clock reading 0.0 for four days was." A tripwire read
against a stale number is not a read.

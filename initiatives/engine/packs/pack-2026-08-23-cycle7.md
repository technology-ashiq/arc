**What this pack is.** The bounded material for a `build-in-public-draft` dispatch. It bounds the
DATA and not the ANGLE. Nothing here is a product detail, a credential, a customer, or an unshipped
plan: every entry is an engineering finding about how this repository tests itself. The
`classification` line is the owner's positive declaration and travels with the dispatch as an input,
because "no internal-only marker was found" is an absence and REQ-06 asks for a declaration.

### #the-evidence-file-that-described-a-directory-that-never-existed

A phase's evidence bundle contained a sentence saying a scrubbed transcript had been stored at a
particular path. The path had never existed. `git log --all` on it returned nothing, and the
ignore-file explicitly un-ignored it, so it was not a case of something written and then excluded —
nothing was ever written there.

The sentence was not a lie anyone told. The storage code had been written that same session, the
destination was in the plan, and the sentence described what *should* have happened. One `ls` would
have caught it. Nobody ran one for six days, and the identical miss then cost a later phase the one
artifact that would have said whether a bug was in the prompt or in the schema.

The rule it produced: **look at the artifact before carrying its verdict.** A report about a file is
not the file.

### #the-test-that-was-green-because-it-was-reading-our-own-banner

A test asserted that a stored transcript contained "the driver's lines, not merely exist" — its
comment said exactly that. It searched the file for a marker string.

The marker was in a banner our own code prints, in the parent process, before the driver even
starts. The test file contained zero bytes of the thing it claimed to be checking. Delete the code
that forwards the driver's output entirely, and the test stays green.

Two independent reviewers, given different assignments and no knowledge of each other, both found it
within the hour. That agreement was the signal: in this codebase two reviewers on different surfaces
almost never overlap, so when they do, the finding is not subtle.

### #a-preview-flag-that-spent-real-money

A command-line flag took a directory path. Its validation rejected an empty value and an absent one,
and treated every other string as a deliberate path.

So `--transcript-dir --dry-run` consumed `--dry-run` **as the path**. The preview flag was never
seen. A caller asking to see what *would* happen got a real dispatch against a real model, a real
charge, and a permanent entry in an append-only ledger — plus a directory on disk literally named
`--dry-run`.

The guard was written against the two failures someone had already had. The third was the one nobody
had had yet.

---

### #the-termination-step-that-was-wrong-twice-in-the-same-comment

A configuration file carried the procedure for firing an automated contractor: revoke its
credential, then delete its row. The comment argued the deletion was "the only form with no
reachable remainder".

That wording was a correction. The *previous* wording had said something else, was measured, was
found false, and was replaced. The replacement was never measured. When someone finally ran it, the
contractor was still reachable with the row deleted — so a false claim about a safety mechanism had
been corrected into a different false claim about the same mechanism, in the same comment, and both
had been believed.

Nothing in the codebase could have caught either one, because the code enforced nothing. A
termination step is a claim about behaviour, and it belongs in a test rather than in prose.

---

### #ci-killed-three-of-my-own-assertions

After all of the above was fixed, continuous integration failed — on three assertions written that
same day, by the person fixing the vacuous tests.

One compared against a variable the test framework does not define, so it was comparing against an
empty string. One asserted that a fallback chain was never walked, in a configuration that had no
fallback chain. One searched a receipt for a field the receipt does not emit.

All three would have passed forever. The useful part is not that they were caught; it is that the
three-machine matrix caught what one machine could not, on work whose entire subject was tests that
pass while measuring nothing.

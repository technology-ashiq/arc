# Fixed defects — the launch lane's running list

Every attacker prompt carries this file, with one instruction: **check each line in every OTHER
file you are shown, not only the file it was fixed in.** Every attacker pass adds its fixed holes
here, one line each.

Format: **defect** — where it was fixed — *the pattern to check elsewhere*.

- **Blanking comments before strings read the `//` inside `"https://..."` as a comment and ate the rest of the line, braces included, so verify-is-probe found no verify at all** — `lib/scan.mjs` `verifyBody` blanks strings and comments in one pass, Phase 00 — *any other source scanner in the lane (`specifiers`, `defaultWordHits`) that treats a token inside a string as code*
- **The slot-names-provider rule fired on the slot's own `id` (`ledger-source`), which happens to equal its provider's id** — `launch-lint.mjs` exempts `id`, Phase 00 — *every rule that compares a field VALUE against another file's ids*
- **A runner killed while holding the lock left its attempt with no receipt, so "every attempt ends with exactly one receipt" held only for workers** — `lib/runner.mjs` closes the orphaned attempt as failed, with a receipt, on takeover, Phase 00 — *every exit path of `runAttempt`, including the approval pause and refusals*
- **Windows reports a SIGKILLed child as plain exit 1, so a reason built from the exit code named the wrong cause** — `lib/runner.mjs` reason says the worker ended without a result, Phase 00 — *any code that infers a cause from `status` or `signal`*
- **`withLock` treats a holder older than ten minutes as a reused pid and breaks its lock, while a hosting apply may run fifteen** — `lib/runner.mjs` refuses on a LIVE holder before waiting, Phase 00 — *any other caller of `withLock` with a long critical section*
- **Paths node prints on Windows carry backslashes that bash reads as escapes when a helper's output is eval'd or globbed** — `tests/launch/make-fixture.mjs` prints forward slashes in quoted exports, Phase 00 — *every helper whose output bats evals or globs*
- **`VAR=x run cmd` in bats never exports VAR to the child, so an env-steered fixture ran unsteered** — `tests/launch-runner.bats` uses `run env VAR=x`, Phase 00 — *every `run` in every launch suite*
- **`ctx.write` resolved symlinks only on the ancestors, so a LEAF link (`root/evil -> /outside`) carried a write out of the venture root** — `lib/ctx.mjs` `confinedPath` lstats every component to the leaf and refuses any link, attack 06cbc03 L1 — *every path check that validates one resolution and then writes through another (validate one read, use another)*
- **A rehearsal's gate-3 refusal was terminal on the first run but a re-run read the recorded approval id as pending and answered "awaiting" (exit 5)** — `lib/runner.mjs` `gate()` refuses from the record, attack 06cbc03 L2 — *every state the runner treats as terminal: does every re-entry path honour it?*
- **`typeof null === "object"` let `"slots": null` past the state shape guard into a TypeError** — `lib/state.mjs` `check()`, attack 06cbc03 L3 — *every `typeof x === "object"` guard in the lane*
- **`ctx.fetch` checked only the first URL and let `fetch` follow redirects to a host nobody checked** — `lib/ctx.mjs` forces `redirect: "manual"`, attack 3b48ed1 B1 — *every allowlist checked once on an input that the callee may replace (redirects, retries, resolved names)*
- **`node:` built-ins were waved through, so an adapter could import `node:fs`/`node:child_process`/`node:https`, call bare `fetch()` or read `process.env`, walking round every ctx guard** — `lib/scan.mjs` allows only pure built-ins and refuses ambient globals; `lib/worker.mjs` strips undeclared env keys before the import, B2 — *any boundary enforced only inside an object the guarded code is free not to use*
- **Import regexes assumed whitespace, so `import{x}from"pkg"` matched nothing; commented imports were counted** — `specifiers` reads comment-stripped source for any `from"x"` / `import"x"`, B3 — *every regex over source code: minified syntax, comments, template literals*
- **The adapter path was data the runner trusted: `providers/x/../../tmp/evil.mjs` ran, and backslashes passed on one OS only** — `lib/runner.mjs` requires `<id>.mjs` inside the providers tree, B4 — *every path built from a registry value*
- **The parent hashed the adapter file and the worker imported a second read of it, and re-read the registry too** — the worker gets the checked row from the parent and imports the hashed bytes from a data: URL, B5 — *validate one read, use another: every check-then-load pair*
- **Gate check-then-emit ran outside the lock, so two applies made two requests and state kept the one the owner did not approve** — `gate()` checks, emits and records under one lock, B6 — *every check-then-act on shared state*
- **An unrecorded sensitive-action request left the slot "awaiting" an id that did not exist** — `runAttempt` fails the slot instead, B8 — *every path that stores an id returned by a call that can return null*
- **`--venture-root .` pointed ctx.write at arc's public repo** — `apply` refuses arc's tree, its ancestors and a filesystem root, B9 — *every user-supplied directory that becomes a write boundary*
- **The lint self-test edited LF literals into files a Windows checkout gives it as CRLF** — baseline copies are LF-normalised, B14 — *every test fixture that edits checked-out text by literal match*
- **The worker's arguments travelled as one argv JSON element, which Windows caps near 32k and re-parses for quotes** — `lib/runner.mjs` writes them to a file the worker reads, attack 06cbc03 B4 — *every JSON or path handed to a child process as a single argument*
- **`ctx.write` accepted `nul`, `C:foo` and `file.txt:stream`, which are files on Linux and something else on Windows** — `confinedPath` refuses `:`, device names and trailing dots/spaces per component, attack 06cbc03 B6 — *every path segment built from data: slugs, ids, file names*
- **`specifiers` kept string text and matched `from 'x'` inside an ordinary string, refusing a clean adapter -- the verifyBody string/code defect's twin, left open in the scanner beside it** — string literals are read as tokens and count only after `from`/`import`/`import(`/`require(`, attack 05704b3 L1 — *every scanner that searches source text for a keyword followed by a quote*
- **Two bats fixtures edited a checked-out YAML with a sed `$` anchor that misses on a CRLF line, and guarded the edit with a whole-file `cmp` that a CR-only difference would pass** — `tr -d '\r'` first and a `grep` for the edited line, attack 05704b3 L2 — *every test that edits a checked-out file by pattern*
- **A new product landed without its `arc-products.mjs` CATALOG entry, so `--status` never listed it (products.bats, every leg)** — CATALOG gains `launch`, CI 37144642041 — *every new product birth: manifest + CATALOG + face room + golden + wiki, in one change*
- **`grep -q $'\r'` on Git Bash reads in text mode and never sees a CR, so the CRLF fixture's own guard failed on the Windows leg only** — the guard reads bytes with node, CI 37144642041 — *every byte-level assertion made with a text tool*
- **`verify` re-implemented apply's checks and kept only half: no venture-root guard (arc's tree accepted, a missing root a raw ENOENT) and no adapter-path containment** — `checkVentureRoot` and `checkAdapter` are shared functions every adapter-running verb calls, attack 405007a B1/B2 — *every NEW verb that runs an adapter: does it call the shared guards, or restate them?*
- **`verify` read the slot's provider, attempt and adapter check outside the lock, then ran under it** — `probeOne` reads everything inside the lock, B4 — *validate one read, use another, across a lock boundary*
- **A killed verify left the previous run's `last_verify`, which the log then printed as this run's reason** — `last_verify` is cleared before the probe and a missing answer is named, B3 — *every "read the result after the child" that can read a result the child never wrote*
- **One locked slot threw out of `verify --all`, losing the summary and never trying the rest** — a held lock skips that slot and the loop continues, exit 3 only when nothing failed, B6 — *every loop whose body can throw a per-item refusal*
- **Adapter-supplied strings (resource ids, reasons, answerers) were printed raw, so a newline or escape could forge a line** — `clean()` on every printed adapter value, B7 — *every terminal line that interpolates provider or adapter data*

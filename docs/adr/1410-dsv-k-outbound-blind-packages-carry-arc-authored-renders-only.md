# ADR 1410 — DSV-K: outbound blind packages carry arc-authored renders only

**Status:** accepted
**Date:** 2026-08-23
**Product:** `design`
**Reversibility:** one-way
**Revisit trigger:** none that reopens the rule itself. The only revisitable part is the
mechanism: if the packager's authorship check is found to pass a non-arc render, the check is
strengthened — the rule is not relaxed.

## Context

[ADR-0040](0040-des-h-req01-two-external-evidence-streams.md) requires REQ-01's two external
blind evidence streams: real designers and real users, outside the repo. Those packages leave
arc and reach people.

Design v2 introduces two new classes of image into the same pipeline: **gallery screenshots**
owned by third parties, and **rival drafts** generated by v0 and Stitch. A package that carried
either outward would be, at once, a copyright exposure and a claim of authorship arc did not
earn.

This is a one-way door because publication is irreversible: an outbound package is indexed,
cached, and forwarded beyond recall. The repo already has a near miss on record — ADR-0040
required only that arc's *authorship* be hidden and said nothing about product confidentiality,
and that gap nearly put LexOS mockups on a public subreddit.

## Options considered

1. **Rely on reviewer discipline at packaging time** — pros: no code / cons: the near miss
   above happened under exactly this control.
2. **A packager lint that refuses non-arc renders** — pros: authorship honesty and copyright
   become one mechanical gate / cons: the gate must know provenance, which means every render
   carries it.

## Decision

Option 2. The packager **refuses** any rival draft or gallery image in a package leaving the
repo. Authorship honesty and copyright are enforced by one gate, not two policies.

Because the gate reads provenance, provenance becomes mandatory on every render receipt rather
than optional metadata.

## Consequences

Easier: one refusal covers both risks, and the refusal is testable — the acceptance for this
gate is that it **refuses a planted non-arc render**, not that it passes a clean one. Harder:
the outbound path now depends on provenance being correct upstream, so a render whose
provenance is missing must fail closed rather than default to arc-authored.

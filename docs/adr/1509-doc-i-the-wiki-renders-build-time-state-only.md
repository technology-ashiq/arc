# ADR 1509 — DOC-I: the wiki renders build-time tree state; live state belongs to the face

**Status:** accepted
**Date:** 2026-09-25
**Product:** docs
**Reversibility:** two-way

## Context

Locked (DOC-I). The face app already shows live state. A wiki that shows it too competes, and one of
them will be wrong.

## Decision

Pages carry only facts derivable from committed files at build time: manifest fields, PROGRESS
machine-header values, ADR header fields, process fields, frontmatter. No burn charts, no event
counts, no spine reads, no `gh` / network calls, no reads of `.claude/state/`. `wiki-build` is
pure over the tree it is given.

## Consequences

A lane page shows its PROGRESS header as of the commit, which is also what makes the dirty-diff
check (ADR-1504) possible: a page that read live state could never be regenerated byte-identically.
